# Roster-Bot
A simple discord bot to keep track of whose turn it is to write the meeting agenda and minutes for the ChaosApp project.

##Commands
/minutes-next: Retrieves the name of the current person assigned for writing the minutes.
/minutes-done: Mark that the current assigned person had finished writing the minutes.
/minutes-peek: Check who is assigned to minute writing after the current assignee.

/agenda-next: Retrieves the name of the current person assigned for writing the agenda.
/agenda-done: Mark that the current assigned person had finished writing the agenda.
/agenda-peek: Check who is assigned to agenda writing after the current assignee.
